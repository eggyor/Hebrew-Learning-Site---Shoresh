# 字根花園

**字根花園**是一款用來學習聖經希伯來文高頻詞的互動式單詞學習器。介面以羊皮紙、木作與古金色裝飾呈現，支援桌面與手機瀏覽。

## 功能

- **今日練習**：每輪可選 3、5 或 8 個新詞；題目會以不同方式出現，答錯的詞會在本輪再次出現。已學過的詞也能用「加強練習」複習最弱的 10 個詞。
- **詞牆**：瀏覽 984 個詞，依待複習、多義詞、詞性等條件篩選，也能用希伯來文、音譯、中文或英文搜尋。點選詞卡可查看發音、全部常見義項、記憶鉤子和熟練度；已學會的詞在游標停留時會有魔法般的金白色光效。
- **熱度場景**：連續完成練習會逐步豐富全螢幕書房插圖，最多七個階段；漏練的日子會讓場景退回相應階段。桌上的書可展開最多五個最近學會的詞；全部詞都學完後會改為隨機顯示五個詞。電腦可將游標停在書上約 0.3 秒顯示清單，點一下固定、再點一下收起；手機以點按顯示或收起。
- **進度與備份**：查看已學詞、熟練詞、完成輪數和最高連對；可匯出 JSON 備份，或以合併、覆蓋方式匯入備份。
- **適合手機與電腦**：手機可從瀏覽器加入主畫面，以接近 App 的方式開啟。答題途中離開時會先顯示提醒。

## 在本機預覽

這是純靜態網站，不需要建置工具或伺服器程式。請在專案資料夾啟動本機靜態伺服器：

- Windows：`py -m http.server 8000`
- macOS / Linux：`python3 -m http.server 8000`

接著在瀏覽器開啟 `http://localhost:8000`。請使用本機伺服器預覽，不要直接以 `file://` 開啟；離線快取和部分瀏覽器功能需要 HTTPS 或 localhost。

## 部署到 GitHub Pages

1. 建立 GitHub repository，將本專案全部檔案放在 repository 根目錄，並保留隱藏檔 `.nojekyll`。
2. 開啟 repository 的 **Settings → Pages**。
3. 在 **Build and deployment** 選擇 **Deploy from a branch**，再選 `main` 分支與 `/(root)` 資料夾。
4. 等待 GitHub Pages 完成部署後，使用頁面提供的網址開啟網站。GitHub Pages 使用 HTTPS，可支援加入主畫面和 Service Worker 離線快取。

初次連線後，網站會快取主要程式、樣式和插圖供離線使用。字體由 Google Fonts 提供，離線時會改用系統字體。

## 學習資料與備份

- 學習進度保存在瀏覽器的 `localStorage`，不需登入，也不會自動同步到其他裝置或瀏覽器。
- 換裝置、換瀏覽器或清除網站資料前，請先從「進度」頁匯出備份，再於另一處匯入。
- 合併匯入會為每個詞保留較佳的熟練紀錄；覆蓋匯入則以備份中的進度取代目前資料。也可使用 JSON 檔或備份文字匯入。
- 每日練習紀錄會保存在備份中，供熱度場景計算連續練習階段。

## 專案結構

```text
index.html                  網頁入口、字體與樣式載入
manifest.webmanifest         加入主畫面所需的網站資訊
sw.js                        Service Worker 離線快取
css/style.css                共用樣式與詞牆樣式
css/hero.css                 首頁樣式
css/heat.css                 熱度場景、發光文字與互動樣式
js/words.js                  希伯來詞表（984 筆）；新增詞請加在陣列最後，勿更改既有 id
js/store.js                  本機存檔、備份匯入匯出、每日活動紀錄
js/core.js                   詞表處理、音效與共用單詞元件
js/hero.js                   首頁內容
js/heat.js                   熱度階段、場景定位與書本互動
js/quiz.js                   題目、答題流程與熟練度更新
js/views.js                  詞牆、進度頁與分頁導覽
js/app.js                    啟動網站與 Service Worker
icons/                       場景插圖、羊皮紙材質、按鈕素材與網站圖示
```

## 維護備註

- 修改程式、樣式或快取資源後，請將 `sw.js` 開頭的 `VERSION` 加一，讓使用者的瀏覽器下載新快取。
- 新增詞彙時請保留現有詞彙 id，避免既有學習紀錄失去對應。
- 詞表由人工整理；拼寫和釋義仍建議對照 BDB、HALOT 等希伯來文詞典。
